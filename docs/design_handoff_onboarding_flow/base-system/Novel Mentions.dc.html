Every song, movie, quote and book an author reaches for — catalogued where it appears, why it's there, and what the character was thinking. Warm and literary, but playful: a good bookstore meets a music app. Below: all five screens in light & dark, component states, and the full token spec for handoff.

Addendum 02

Add a book

The Library-search “Add a book” CTA opens a full-height sheet: search a public book database, pick a result, confirm. The book is added to the reader's local library only — no community publishing yet. New books have no curated mentions, so the empty Book-detail state is defined here; their palette is derived from the cover (house fallback if none).

Addendum 03

Search across books & mentions

The Library search keeps its “Search books & mentions” scope. Results are split into two labelled groups — Books and Mentions — so book titles and the references inside them never blur together. A mention result shows its kind, attribution and which book it's in, and taps straight through to Mention detail. One combined empty state covers a query that matches neither.

Addendum 04

Notes on a whole book

Notes can attach to a whole book, not only a mention. An overflow (⋯) menu on the Book-detail header adds one; existing book-level notes surface in a pinned card under the chips. In “My notes”, a whole-book note's context line reads “A note on the book · {book}” instead of naming a mention.

Per-book palette

Derived from the cover. Fills 4 roles: header bg, on-header text, chip-active / FAB, soft tint.

on-header#FFFFFF

soft-tintbook.primary @ 8% L / 18% D

User-added books have no curated palette yet: derive the primary from the cover image at add time (dominant vibrant colour, guarded so on-header text stays white / AA). If none, fall back to the house palette — primary #4A4038 L / #C8BCAC D.
